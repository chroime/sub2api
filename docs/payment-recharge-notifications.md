# 充值成功邮件通知

在 **后台 → 系统设置 → 支付设置 → 充值成功邮件通知** 中填写收件邮箱并开启通知，然后点击“保存充值通知设置”。支持换行或逗号分隔的多个邮箱，最多 10 个；保存时会校验格式并忽略大小写去重。默认关闭，可先保存停用草稿。

收件人由支付设置独立管理，与管理员登录邮箱、个人资料通知邮箱、账号限额告警邮箱均分开。发信仍使用系统设置中的 SMTP 服务。

只有本站余额充值订单已完成入账、状态进入 `COMPLETED` 后，系统才发送管理员通知。定额收款码和其他支付服务商经过同一充值履约流程时均适用；未付款、取消、超时以及尚未入账的订单不会发送成功通知。购买订阅沿用原通知流程。

邮件包含充值用户、站内订单号、商户订单号、实际支付币种和金额、到账 USD 额度、支付方式和北京时间完成时间。管理员邮件与原有用户充值成功邮件独立发送，一位收件人发送失败仍会继续处理其他收件人，邮件失败不影响已完成的充值。

可在 **智能运维 → 发送记录 → 用户邮件** 中按“充值成功通知（管理员）”筛选。记录中的平台用户是充值用户，“实际收件邮箱”是支付设置中的管理员邮箱；详情可查看实际正文及成功、失败或跳过原因。“已发送”表示 SMTP 服务器已接受邮件，是否进入收件箱以邮箱为准。

重复支付回调不会再次触发完成通知；同一订单和收件人也复用现有邮件去重标记。此功能不会补发历史订单，不会在发送结果未知时自动重发。

本地保留 ¥0.10 测试金额和对应收款码。配置并启用通知后，可完成一笔新的小额充值，再核对余额、订单状态、收件邮箱及发送记录。

管理员配置 API 使用 `GET/PUT /api/v1/admin/payment/config`，新增字段：

```json
{
  "admin_recharge_notify_enabled": true,
  "admin_recharge_notify_emails": ["billing@example.com"]
}
```

这两个字段不会出现在普通用户的 `/api/v1/payment/config` 或 `/api/v1/payment/checkout-info` 响应中。启用时必须提供至少一个有效邮箱；请求未包含的字段保持原值，关闭通知时可保留收件人草稿或显式清空。
