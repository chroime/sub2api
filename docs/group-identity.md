# 分组身份标识

在 **后台 → 分组管理 → 创建分组／编辑** 中，可以在分组名称下方设置独立的“身份标识”。

- 选择“自营”“官方”“第三方”预设，或输入自定义短文字。
- 标签最多12个Unicode字符，只支持单行文字。
- 选择常用颜色，或使用颜色选择器自定义。自定义颜色保存为六位十六进制色值，标签自动使用对比清晰的文字颜色。
- 预览区域即时显示“身份标识＋平台图标＋分组名称”；保存分组后在其他展示位置生效。
- 选择“不显示”或清空文字即可移除标识。旧分组默认未配置，不会按名称、平台或专属权限推断身份。

身份标识用于分组列表、API密钥分组选择、模型广场、账号分组、可用渠道、订阅和套餐等位置。它只表示管理员填写的展示信息，不改变名称、费率、权限、模型、账号绑定或请求路由；标识图标不代表额外的外部认证流程。

管理API的新建和更新请求支持：

```json
{
  "identity": {
    "label": "自营",
    "color": "teal"
  }
}
```

颜色支持 `teal`、`blue`、`amber`、`violet`、`rose`、`gray`，或严格的 `#RRGGBB`；自定义颜色会规范为小写。标签非空但未指定颜色时使用 `teal`。

更新请求省略 `identity` 或传 `null` 保留原值，传 `"identity": {}` 清空。复制分组会保留身份标识。分组响应中的 `identity` 为公开展示字段，未配置时为 `{}`。

迁移289仅增加 `groups.identity JSONB NOT NULL DEFAULT '{}'`，保留现有分组、配置及价格。部署后可逐组配置准确身份。
