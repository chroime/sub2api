# 上游分组描述导入设计

## 目标

在“智能运维 → 分组导入”中读取上游分组的 `description`，在导入列表和详情中展示，并允许管理员在生成正式导入预览前编辑。编辑后的描述写入现有导入预览 JSON，应用导入时沿用该冻结值；本功能不修改已存在的本地分组描述，也不新增数据库迁移。

## 当前上下文

分组导入流程由上游治理服务读取远程目录，前端 `ImportPanel.vue` 将远程分组映射到已存在的本地分组，调用 `Preview` 冻结选择后再调用 `Apply` 创建或更新上游账号。当前 `RemoteGroup` 没有描述字段：Sub2API 的 `/api/v1/groups/available` 响应中的描述会被丢弃，New API 的 `desc` 被用作分组显示名称。导入目标是已有本地分组，不会创建本地分组，因此描述编辑的作用域限定为本次远程导入记录。

## 方案与取舍

采用“目录字段 + 导入选择字段 + 预览冻结”的方案：

1. 后端 `RemoteGroup.Description` 解码并通过目录 API 返回；前端远程分组类型同步增加 `description`。
2. 前端为每个远程分组维护一个描述草稿，初始值来自目录；详情区域提供可编辑文本框，编辑后使旧预览失效，要求重新点击“预览”。
3. `Selection.Description` 随预览请求发送。后端将其裁剪空白、限制长度并在为空时回退到快照中的远程描述，然后把规范化后的值保存到 `PreviewRow.Selection`。因此应用阶段只使用已审核的冻结数据，不接受应用请求临时篡改。
4. 预览区域展示冻结后的描述，应用结果继续复用当前预览数据；描述不会写入目标本地分组，也不改变账号、倍率、绑定或密钥逻辑。

这个方案保留现有预览的防篡改边界，避免为描述引入新的写入接口或数据库表。空描述合法，表示没有上游说明；上游没有字段时保持为空。编辑值的最大长度与当前远程目录校验保持一致，为 300 个字符。

## 上游字段映射

- Sub2API：从 `/api/v1/groups/available` 的 `description` JSON 字段读取；快速观察和完整目录使用相同字段。
- New API：保留现有 `desc` 作为显示名称。只有响应提供独立的 `description` 字段时才填充 `RemoteGroup.Description`，避免把现有名称重复显示为描述。
- 其他协议继续返回不带描述的空字符串，并保持现有“不支持”判断。

## 数据流

```text
上游 groups/available 或 self/groups
        │
        ▼
RemoteGroup{ name, description, ... }
        │ Catalog / Snapshot
        ▼
ImportPanel 的 GroupChoice.description 草稿
        │ 编辑后重新预览
        ▼
Selection.description ── Preview() 规范化并冻结 ──▶ PreviewRow.Selection.description
        │
        └── Apply() 使用同一冻结预览；不改本地 Group
```

## 校验与错误处理

- `description` 始终按字符串处理，去除首尾空白；空字符串保留为空。
- 上游描述或管理员编辑值超过 300 个字符时，目录收集或预览分别返回现有 `ErrUnsupported` / `ErrInvalid`，不会截断静默写入。
- 旧客户端不发送 `description` 时，后端预览从快照远程分组描述回退，保持向后兼容。
- 编辑描述后清除旧预览和应用结果，防止界面显示的描述与服务端冻结预览不一致。

## 测试范围

- 后端目录测试：Sub2API 完整目录和快速观察保留 `description`；New API 独立 `description` 可读取且 `desc` 仍作为名称。
- 后端预览测试：未提供描述时回退快照值；提供编辑值时冻结规范化后的描述；超长值拒绝；应用传给本地账号适配器的其他字段保持不变。
- 前端 API 类型和组件测试：远程描述渲染、详情编辑、编辑后预览失效、预览显示冻结描述，并验证预览请求带上编辑值。
- 运行相关 Go 包测试和 `ImportPanel.spec.ts`；不触碰工作区已有的 Grok、IQ 页面冲突及测试产物。

## 不在本次范围

- 不更新已有本地分组的 `description`。
- 不创建新的本地分组。
- 不改变账号名称、账号备注、倍率、模型白名单、密钥或绑定持久化逻辑。
- 不新增数据库迁移或新的预览 API。
