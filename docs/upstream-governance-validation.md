## 本地浏览器与数据库核对

运行实际生产构建的本地服务，使用独立应用数据库、虚构管理账号和标注为「本地样例」的目录。样例域名为保留的 `.invalid` 域名，管理会话和推理密钥均为虚构值。目录与已有远程密钥的密文作为测试夹具预置，平台登录/采集/建钥的协议行为由连接器 fixture 测试覆盖。

| 操作 | 数据库/页面结果 |
| --- | --- |
| 选择上游分组与本地分组、生成预览 | 治理账号数量仍为 0 |
| 明确确认首次导入 | 创建账号 #1，账户成本 0.8000；本地分组销售倍率仍为 1.5000 |
| 重复获取/应用同一预览 | 治理账号数量仍为 1 |
| 保存定时检查配置 | 保存指定模型及 30 分钟周期，检查记录数仍为 0 |

| 确认事件已读 | 对应事件 acknowledged 为 true |
| 重启服务后将同一绑定映射到混合分组 | 预览显示 0.8→0.9 和分组 2→3；确认后仍为账号 #1，成本 0.9000、目标销售倍率 2.0000，旧自动计费探测/同步均为 false |

Playwright 浏览器控制台无错误。页面截图通过人工视觉检查，覆盖冻结预览、成本与售价区分、绑定和事件/检查历史。

## 验证边界

本次没有使用真实上游账号、生产数据库或生产配置。上述结果证明本地实现、平台协议样例及并发/恢复逻辑通过验证，不代表所有 New API/Sub2API 定制部署都已实测连通。真实 WAF、用户权限、验证码、Passkey 和会话有效期仍按实际站点返回处理。

目标分组元数据在预验证和本地适配器应用前各复核一次；此版本没有为整个目标分组设置实现覆盖所有配置字段的事务级 CAS。治理从不写目标分组的销售价。账号配置及其成员绑定则在数据库锁内进行原子校验和写入。
