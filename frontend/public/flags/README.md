# Language Flags

Local PNG assets from FlagCDN (https://flagcdn.com), displayed at 24 x 18 pixels.
Bundled locally so language flags do not depend on system emoji support or an
external image request at runtime.

- `us.png`: https://flagcdn.com/48x36/us.png
- `cn.png`: https://flagcdn.com/48x36/cn.png
